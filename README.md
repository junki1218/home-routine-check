# 帰宅後のルーティンチェック

帰宅後にやることを 1〜9 まで、**カードを1枚ずつ**たどってチェックしていくアプリです。
スマホ・iPad の縦持ちを基準に作っています。

---

## 使い方

### 開く

`index.html` をブラウザで開くだけで動きます。インターネット接続もインストールも不要です。

iPad / iPhone で使うときは、Safari で開いたあと
**共有 → ホーム画面に追加** しておくと、アプリのように全画面で使えます。

### 子どもの操作

1. 1番のカードが出る
2. できたら **「できた！」**（緑）→ 自動で次のカードへ
3. おうちの人に見てほしいときは **「チェック待ち」**（オレンジ）→ 次のカードへ進む
4. 9番まで終わると **「完了」** ボタンが出る → 押すと紙吹雪が出る

左右スワイプ、上のドット（1〜9）タップ、「まえ／つぎ」ボタンでも移動できます。
押しまちがえたときは **「まちがえた（もどす）」** で戻せます。

### 保護者の操作

右上の **「保護者」** ボタンから、いつでも開けます。

- **チェック待ち** … 子どもが申し出た項目が並ぶ。**OK** を押すと「できた」になる
- **きょう** … 今日の9項目の状態と時刻
- **記録（1か月）** … 日ごとの達成数と、項目ごとの時刻

チェック待ちが残っている間は、右上のボタンにオレンジの数字が出ます。

## 仕様

### チェックの条件

| 番号 | 条件 |
|---|---|
| 1〜5, 7, 8 | いつでもチェックできる |
| **6**（もう一度1番から見直す） | **1〜5 がすべて「できた」になっていないとチェックできない** |
| **9**（終わったことを報告する） | **1〜8 がすべて「できた」になっていないとチェックできない** |

- 例：2番が「チェック待ち」の間は 6番 をチェックできませんが、**7番・8番は先にチェックできます**。
- チェックできないカードでは、理由（「2番が『チェック待ち』です」など）が画面に出ます。
- **チェック待ちが1つでも残っている限り「すべて完了」にはなりません。**

### 日付の切り替わり

**深夜3時**に新しい一日が始まります。
夜遅くにやった分も、その日の記録として残ります（日付がずれません）。

### 記録

- タップした時刻を**すべて**記録します（できた／チェック待ち／保護者OK／取り消し）。
- 保存先は**その端末のブラウザの中**（localStorage）です。外に送信されません。
- **31日分**を保持し、それより古い日は起動時に自動で消えます。
- 別の端末・別のブラウザには引き継がれません。

## ファイル構成

```
HomeRoutineApp\
├─ index.html          画面の骨組み
├─ styles.css          見た目
├─ app.js              動き・判定・記録
├─ assets\             カードの画像を置く場所（空でも動く）
├─ 画像生成指示書.md    クレイアニメ風イラスト9枚の生成プロンプト
└─ README.md           このファイル
```

## カードの絵の差し替え

いまは絵文字で表示しています。
`assets\card1.png` 〜 `assets\card9.png` を置くと、**自動でその画像に切り替わります**。
アプリ側を直す必要はありません。生成の指示は `画像生成指示書.md` にあります。

## 項目を変えたいとき

`app.js` のいちばん上にある `CARDS` の配列を書き換えます。

```js
var CARDS = [
  { no:1, title:'カバンの中に…', emoji:'🎒', color:'blue' },
  …
];
```

`REQUIRES` を直すと、「何番が何番に依存するか」も変えられます。

## 記録を消したいとき

保護者画面には消す機能を付けていません（誤操作を防ぐため）。
消す必要があるときは、ブラウザの開発者ツールのコンソールで次を実行します。

```js
__routine.reset()
```
