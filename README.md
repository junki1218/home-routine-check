# 帰宅後のルーティンチェック

帰宅後にやることを 1〜9 まで、**カードを1枚ずつ**たどってチェックしていくアプリです。
スマホ・iPad の縦持ちを基準に作っています。

---

## 使い方

### 開く

`index.html` をブラウザで開くだけで動きます。インターネット接続もインストールも不要です。

iPad / iPhone で使うときは、Safari で開いたあと
**共有 → ホーム画面に追加** しておくと、アプリのように全画面で使えます。

### 子どもの操作

1. 1番のカードが出る
2. できたら **「できた！」**（緑）→ スタンプとキラキラが出て、自動で次のカードへ
3. おうちの人に見てほしいときは **「チェック待ち」**（オレンジ）→ 次のカードへ進む
4. 9番まで終わると **「完了」** ボタンが出る → 押すと紙吹雪と、その日のスタンプ9個が並ぶ

左右スワイプ、上のドット（1〜9）タップ、「まえ／つぎ」ボタンでも移動できます。
押しまちがえたときは **「まちがえた（もどす）」** で戻せます。

### 「うごく」／「おと」ボタン

右上の2つのボタンで、演出を別々に切れます。設定はその端末に記憶されます。

| ボタン | 押すと |
|---|---|
| **✨うごく** → 🤫しずか | アニメーションが全部止まる |
| **🔊おと** → 🔇むおん | 効果音が鳴らなくなる |

端末側で「視差効果を減らす」を設定していれば、**初回から自動で「しずか」で始まります**。

### 効果音

音声ファイルは使わず、ブラウザがその場で音を合成しています（ダウンロードなし・権利関係なし）。

| 場面 | 音 |
|---|---|
| できた！ | ド→ミ→ソ の上がる3音 |
| チェック待ち | 下がる2音（やわらかめ） |
| カードを送る | さらっという送り音 |
| もどす／やりなおし | 下がる2音（低め） |
| 保護者のOK | 上がる2音 |
| 完了 | ド・ミ・ソ・ド のファンファーレ＋きらきら |
| できない操作 | 低い短音 |

ブラウザの制限で、**最初に画面をどこか1回タップするまで音は鳴りません**（仕様です）。

### 保護者の操作

右上の **「保護者」** ボタンから開きます。タブは4つです。

- **OK待ち** … 子どもが申し出た項目が並ぶ。**OK** を押すと「できた」になる
- **きょう** … 今日の9項目の状態と時刻。**「やりなおし」**で「できた」を取り消せる
- **記録** … 1か月分。日ごとの達成数と、項目ごとの時刻
- **せってい** … パターン認証の設定・変更・解除

チェック待ちが残っている間は、右上のボタンにオレンジの数字が出ます。

### やりなおし（「できた」の取り消し）

「きょう」タブで、各項目の右の **「やりなおし」** を押すと、その番号が「まだ」に戻ります。

- 「できた」でも「チェック待ち」でも取り消せます
- **押した記録は消えません。** 「やりなおし」をした事実も時刻つきで残ります
- 9番まで終わって「完了」した後に取り消した場合、その日の完了も取り消されます

### パターン認証（任意・初期はなし）

**初期設定ではロックなしで、誰でも保護者画面を開けます。**
かけたいときは「せってい」タブから設定します。

1. 「パターンを設定する」を押す
2. 3×3のマスを **4つ以上** なぞる（1つずつタップして「けってい」でも可）
3. 確認のためもう一度なぞる → 一致したら保存

設定すると「保護者」ボタンに 🔒 が付き、開くときにパターンの入力を求められます。
**変更・解除**も同じ「せってい」タブから（どちらも今のパターンの入力が必要）。

- パターンはこの端末の中だけに保存され、外には送られません
- ロックがかかるのは**保護者画面だけ**です。子どものチェック操作は今までどおりできます
- **パターンを忘れたとき**は、ブラウザの開発者ツールのコンソールで次を実行すると解除できます

```js
localStorage.removeItem('homeRoutine.lock')
```

## 仕様

### チェックの条件

| 番号 | 条件 |
|---|---|
| 1〜5, 7, 8 | いつでもチェックできる |
| **6**（もう一度1番から見直す） | **1〜5 がすべて「できた」になっていないとチェックできない** |
| **9**（終わったことを報告する） | **1〜8 がすべて「できた」になっていないとチェックできない** |

- 例：2番が「チェック待ち」の間は 6番 をチェックできませんが、**7番・8番は先にチェックできます**。
- チェックできないカードでは、理由（「2番が『チェック待ち』です」など）が画面に出ます。
- **チェック待ちが1つでも残っている限り「すべて完了」にはなりません。**

### 日付の切り替わり

**深夜3時**に新しい一日が始まります。
夜遅くにやった分も、その日の記録として残ります（日付がずれません）。

### 記録

- タップした時刻を**すべて**記録します（できた／チェック待ち／保護者OK／取り消し）。
- 保存先は**その端末のブラウザの中**（localStorage）です。外に送信されません。
- **31日分**を保持し、それより古い日は起動時に自動で消えます。
- 別の端末・別のブラウザには引き継がれません。

## 画面の動きについて

Notion の「UI/UX・アニメーション用語集」の方針（動きには目的を持たせる／読みを妨げない／減らせるようにする）に沿って、
次の動きを入れています。いずれも **「しずか」にすれば全部止まります**。

| 動き | 何を伝えるためか |
|---|---|
| カードが回転しながら飛び出し、次のカードが飛び込んでくる（3D） | カードが入れ替わったこと |
| 絵がゆっくり上下に浮く | 画面が生きていること |
| ✓スタンプ・キラキラ・カードが弾む | 「いまチェックできた」こと |
| ほめことばが一文字ずつ出る（キネティックタイポグラフィー） | できたことへの手ごたえ |
| 上のゲージが伸びる・番号がくるっと回って緑になる | あと何個で終わるか |
| 「完了」ボタンがふわっと脈打つ | 次に押すのはここ、ということ |
| 紙吹雪＋見出しが一文字ずつ＋スタンプ9個が順に並ぶ | 今日ぜんぶ終わったこと |

文字そのものが長く動き続けることはありません（どれも1回かぎり、1秒前後で止まります）。
効果音も同じ考え方で、**操作の結果がわかるときだけ**鳴らしています（BGMはありません）。

## カードの絵の差し替え

`assets\card1.webp` 〜 `assets\card9.webp`（と予備の `.jpg`）を使っています。
差し替えるときは同じ名前で上書きしてください。アプリ側を直す必要はありません。

- 読み込みは **webp → jpg → 絵文字** の順。どれも無ければ絵文字で表示されます
- 元の1024px原寸PNGは `..\.agent_flow\assets\home_routine_app\` にあります
- 生成の指示は [画像生成指示書.md](画像生成指示書.md) にあります

## 項目を変えたいとき

`app.js` のいちばん上にある `CARDS` の配列を書き換えます。

```js
var CARDS = [
  { no:1, title:'カバンの中に…', emoji:'🎒', color:'blue' },
  …
];
```

`REQUIRES` を直すと、「何番が何番に依存するか」も変えられます。

## 記録を消したいとき

保護者画面には全消しの機能を付けていません（誤操作を防ぐため）。
1項目だけ戻すなら「きょう」タブの **「やりなおし」** を使ってください。

記録ごと消す必要があるときは、ブラウザの開発者ツールのコンソールで次を実行します
（パターン認証も一緒に解除されます）。

```js
__routine.reset()
```

## 端末に保存しているもの

| キー | 中身 |
|---|---|
| `homeRoutine.v1` | 31日分の記録（タップ時刻ふくむ） |
| `homeRoutine.motion` | うごく／しずか の設定 |
| `homeRoutine.sound` | おと／むおん の設定 |
| `homeRoutine.lock` | パターン（設定したときだけ） |

いずれもその端末のブラウザの中だけに保存され、外には送信されません。
